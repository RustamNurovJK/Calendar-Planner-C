# 📅 Calendar Planner - Ежедневник

**Курсовая работа по дисциплине «Программирование на языках высокого уровня»**

## 📝 Описание

Консольное приложение «Ежедневник – Календарь» на языке C с графическим интерфейсом на WinAPI. Программа позволяет управлять задачами с привязкой к календарю, получать напоминания и сохранять данные.

---

## 🚀 Функциональность

| Функция | Описание |
|---------|----------|
| 📅 Календарь | Навигация по месяцам (стрелки < и >) |
| ➕ Добавление задач | Название, описание, приоритет, время |
| ✏️ Редактирование | Изменение любых полей задачи |
| ✅ Выполнение | Отметка задач как выполненных |
| 🎨 Цветовая индикация | Зелёный/жёлтый/красный на календаре |
| 🔔 Напоминания | На сегодня и завтра (со звуком) |
| 🖼️ Фоновые картинки | Меняются по месяцам |
| 🎵 Звуки | Запуск, закрытие, добавление, выполнение |
| ✨ Анимация | При переключении месяцев |
| 🕐 Часы | Реальное время в правом верхнем углу |
| 💾 Сохранение | Автоматически в файл tasks.dat |

---

## 🛠️ Установка и запуск

1. Скачайте файл `kursach2.exe` и папку `backgrounds`
2. Поместите их в одну папку
3. Запустите `kursach2.exe`

### 📁 Фоновые картинки (опционально)

В папку `backgrounds` положите 12 BMP-файлов:

| Май | `May.bmp` |

## 🎮 Управление

| Действие | Как выполнить |
|----------|---------------|
| Выбрать дату | Кликнуть на день в календаре |
| Добавить задачу | Нажать «Add», заполнить поля |
| Удалить задачу | Выбрать задачу → «Delete» |
| Отметить выполненной | Выбрать задачу → «Complete» |
| Переключить месяц | Нажать `<` или `>` |

---

## 🔊 Звуки

| Событие | Звук |
|---------|------|
| Запуск программы | Два приветственных сигнала |
| Добавление задачи | Восходящая мелодия |
| Выполнение задачи | Радостный тройной сигнал |
| Напоминание | Три коротких сигнала |
